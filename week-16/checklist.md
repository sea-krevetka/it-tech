# Security Audit Checklist (OWASP Top 10 Based)

**Project:** products-s01
**Date:** 2024
**Auditor:** Student

---

## 🔴 Critical (Критические)

- [ ] **SQL Injection**: Все запросы к БД используют параметризацию или ORM?
- [ ] **Hardcoded Secrets**: В коде нет API ключей, паролей, токенов?
- [ ] **Default Credentials**: Дефолтные пароли админки изменены?
- [ ] **Debug Mode**: Debug режим выключен в продакшене?
- [ ] **Transport Security**: Все данные передаются по HTTPS?

---

## 🟠 High (Высокий риск)

- [ ] **Broken Access Control**: Проверяется ли доступ пользователя к чужим данным?
- [ ] **Authentication**: Используется ли MFA/2FA для критических операций?
- [ ] **Password Storage**: Пароли хэшируются с солью (bcrypt/argon2)?
- [ ] **Session Management**: JWT токены имеют короткое время жизни?
- [ ] **Input Validation**: Валидируются ли все пользовательские входные данные?

---

## 🟡 Medium (Средний риск)

- [ ] **XSS Protection**: Экранируется ли вывод пользовательских данных в HTML?
- [ ] **CSRF Protection**: Используются ли anti-CSRF токены?
- [ ] **Rate Limiting**: Есть ли защита от brute-force атак?
- [ ] **File Uploads**: Проверяются ли типы загружаемых файлов?
- [ ] **Error Handling**: Не выводится ли стектрейс ошибок пользователю?

---

## 🟢 Low (Низкий риск)

- [ ] **Logging**: Логируются ли важные события (логин, изменение прав)?
- [ ] **Monitoring**: Настроен ли мониторинг подозрительной активности?
- [ ] **Dependencies**: Обновлены ли библиотеки с известными уязвимостями?
- [ ] **Backups**: Есть ли регулярные резервные копии?
- [ ] **CORS**: Настроены ли правильные CORS политики?

---

## 🐳 Docker Security

- [ ] **Non-root User**: Контейнер запускается от непривилегированного пользователя?
- [ ] **Image Size**: Используется ли slim базовый образ?
- [ ] **Secrets**: Секреты не хранятся в слоях Docker?
- [ ] **Network**: Контейнер не использует host network mode?

---

## 📡 Network Security

- [ ] **TLS/SSL**: Используется ли валидный SSL сертификат?
- [ ] **Port Exposure**: Открыты только необходимые порты?
- [ ] **Firewall**: Настроено ли ограничение доступа по IP?

---

## 📊 Compliance

- [ ] **GDPR**: Есть ли возможность удалить данные пользователя?
- [ ] **PCI DSS**: Не хранятся ли платежные данные в открытом виде?
- [ ] **Audit Trail**: Ведется ли журнал действий администраторов?
