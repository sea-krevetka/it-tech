# Вопросы для самопроверки

1. **В чем главное концептуальное отличие GraphQL от REST?**
   Главное отличие в том, что REST имеет множество эндпоинтов с фиксированной структурой ответов, а GraphQL имеет один эндпоинт, где клиент сам определяет структуру и объем запрашиваемых данных. В REST сервер диктует, какие данные отдавать, а в GraphQL клиент контролирует это.

2. **Что такое Schema Definition Language (SDL)?**
   SDL — это язык описания схемы GraphQL. Он позволяет определить типы данных, их поля и связи между ними в строго типизированном формате. Например: `type User { id: ID! name: String! }`

3. **Чем Query отличается от Mutation? Могут ли они выполняться параллельно?**
   Query используется для получения данных (аналог GET в REST) и может выполняться параллельно, так как не меняет состояние сервера. Mutation используется для изменения данных (аналог POST/PUT/DELETE) и выполняются последовательно, чтобы избежать конфликтов при изменении данных.

4. **Что такое "резолвер" (resolver) и кто его вызывает?**
   Резолвер — это функция, которая знает, как получить данные для конкретного поля запроса. GraphQL сервер вызывает резолверы автоматически, когда клиент запрашивает соответствующие поля. Резолвер может получать данные из базы, другого API или файловой системы.

5. **Как решается проблема N+1 запросов в GraphQL (dataloader)?**
   Проблема N+1 решается с помощью DataLoader — механизма батчинга и кэширования запросов. Он группирует множество запросов в один и кэширует результаты, чтобы избежать повторных запросов к базе данных. Например, при запросе списка пользователей и их постов, DataLoader выполнит один запрос для всех пользователей и один для всех постов.

6. **Почему в GraphQL сложно реализовать кэширование на уровне HTTP (как в REST)?**
   В REST каждый эндпоинт имеет свой URL, что позволяет легко кэшировать ответы на уровне HTTP. В GraphQL все запросы идут на один эндпоинт, и кэширование по URL невозможно, так как запросы различаются по содержимому. Кэширование нужно реализовывать на уровне данных или использовать инструменты вроде Apollo Client для кэширования на клиенте.
